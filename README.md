# T-Board（ティーボード）

**北海道高等学校遠隔授業配信センター（T-base）対応デジタルノート**

PDFファイルを読み込んで手書きで書き込むことができるブラウザベースの学習支援アプリケーションです。iPadやタブレットでの遠隔授業に最適化されています。

## 🎯 プロジェクトの目標

T-baseで配信される遠隔授業の教材（PDF）に、デジタルペンで直接書き込みを行い、学習をサポートするWebアプリケーションを提供します。

## 🚀 使い方

### 1. T-fab Tile 連携設定（教師）🆕

教師が生徒に配布する URL を作成：
```
https://t-board.netlify.app/?tfab=【○○高校〇年】論理・表現Ⅱ
```

この URL を Google Classroom や学習管理システムで配布

### 2. 初回セットアップ（生徒）🆕

1. 教師から送られた URL をクリック
2. T-Board が開き、名前入力画面が表示される
3. 自分の名前を入力して「参加する」をクリック
4. T-fab Tile が自動的に開く
5. T-Board をブックマーク

**所要時間：約15秒**

### 3. 2回目以降（生徒）🆕

1. T-Board のブックマークを開く
2. 画面上部に「モニタリング教室: ○○高校〇年」バナーが表示される
3. **「参加する」ボタンをクリック**（ワンクリック）
4. T-fab Tile が開く（名前も自動入力済み）
5. T-Board に戻ってもバナーは再表示されません（タブを閉じるまで）

**所要時間：約5秒（1クリックのみ）**

💡 **ポイント**: 
- ブラウザのポップアップブロック対策のため、ボタンクリックが必要です
- 一度参加すれば、同じセッション中はバナーが再表示されません
- バナーの × ボタンで非表示にすることもできます

### 4. ホーム画面にインストール（推奨）🆕

#### **重要：ボタンの表示条件**
インストールボタンは環境によって表示が異なります：

- **Android Chrome / Windows Edge / Chromebook**: 
  - ✅ **HTTPS環境（Netlifyなど）**でアクセスすると「インストール」ボタンが表示されます
  - ❌ ローカル環境（file://）では表示されません
  
- **iPad / iPhone（iOS Safari）**: 
  - ✅ どの環境でも「追加方法」ボタンが表示されます

#### **Android / Windows / Chromebook の場合**
1. ヘッダーの **「インストール」ボタン** をクリック（HTTPS環境で表示）
2. ブラウザのインストールダイアログで **「インストール」** をクリック
3. ホーム画面/デスクトップに T-Board のアイコンが追加されます
4. 次回からアイコンをクリックするだけで起動できます

#### **iPad / iPhone（iOS Safari）の場合**
1. ヘッダーの **「追加方法」ボタン** をクリック
2. 手順に従って操作：
   - 画面下部の **共有ボタン** をタップ
   - **「ホーム画面に追加」** を選択
   - **「追加」** をタップ
3. ホーム画面に T-Board のアイコンが追加されます

**メリット**：
- ✅ ブラウザのURLバーが非表示になり、広い画面で使える
- ✅ アプリのような操作感
- ✅ すぐにアクセスできる

### 5. PDFファイルを開く
1. 「PDFを開く」ボタンをクリック
2. コンピュータからPDFファイルを選択
3. PDFが表示されます

### 6. 書き込みを行う
1. ツールバーからツール（ペン・マーカー・消しゴム）を選択
2. 色と太さを調整
3. キャンバス上でマウス/タッチで描画

**ツールバー位置の変更** 🆕
- ヘッダーの「レイアウト」ボタン（**↑** または **←** アイコン）でツールバーを左/上に切り替え
- **左サイドバー（↑ 表示）**: 画面を縦に広く使える（タブレット縦向けに最適）
- **上部バー（← 表示）**: 描画エリアを最大化（タブレット横向け、小画面端末に最適）
- アイコンは「次に切り替わる方向」を示します
- 設定は自動保存され、次回起動時も適用されます

### 7. ペン専用モードの使用（タブレット推奨）
**デフォルトで有効です。** 手で画面を触っても描画されず、ペンのみに反応します。

1. ツールバーの「ペン専用」ボタンをクリックで手書きモードに切り替え
2. 手書きモードでは指でも描画できます
3. **ペン専用モード時は1本指で自由にスクロール可能**
4. 再度クリックでペン専用モードに戻ります

**推奨**: タブレットではペン専用モード（デフォルト）のままご使用ください。

### 8. ページを移動
- ページコントロールで前後のページに移動
- 各ページの書き込みは自動的に保存されます

### 5. ズーム・スクロール操作
**ズーム**
- 拡大/縮小ボタンで表示サイズを調整（50%-500%）
- 「100%」ボタンで100%にリセット
- 幅に合わせるボタンで画面幅に最適化
- **ピンチズーム**: 2本指でピンチイン/アウトして直感的にズーム（タブレット・スマートフォン）
- ズーム中心は2本指の中点に正確に設定

**スクロール**
- **2本指ドラッグ**: ピンチ操作なしでの平行移動で画面をスクロール
- **スクロールボタン**: 十字配置のボタンを押しっぱなしで連続スクロール
- **ペン専用モード時**: 1本指でも自由にスクロール可能

### 6. 保存
- 「画像保存」ボタンで現在のページをPNG画像として保存

## 🎨 主な機能の詳細

### 描画システム
- Canvas APIを使用した高性能な描画
- Pointer Events APIによる統一された入力処理
- レイヤー構造（PDFレイヤー + 描画レイヤー）
- スムーズな手書き体験

### タッチ操作
- **1本指タッチ**: ペン/マーカー/消しゴムでの描画
- **2本指タッチ**: ピンチイン/アウトで直感的なズーム、または平行移動でスクロール
- **ペン専用モード時**: Apple Pencilで描画、指1本でスクロール、指2本でズーム/パン
- タッチイベントとPointer Eventsの統合処理
- スムーズなマルチタッチ体験

### ペン専用モード
- Pointer Events APIでペン入力を識別
- pointerTypeが'pen'の場合のみ描画を許可
- 'touch'（指）や'mouse'による入力を無視
- ペン専用モード時も2本指ピンチズームは有効
- タブレット学習に最適

### ページ管理
- ページごとに注釈を個別保存
- ページ切り替え時の自動復元
- メモリ効率の良いデータ管理

### 履歴管理
- 最大50ステップの履歴保存
- 元に戻す/やり直し機能（キーボードショートカット対応）
- ページごとに独立した履歴

## ⚠️ 注意事項

- このアプリケーションはブラウザ上で動作し、データはローカルのみに保存されます
- ページを閉じると書き込みデータは失われます（今後LocalStorage対応予定）
- 大きなPDFファイルは読み込みに時間がかかる場合があります
- ブラウザの互換性: Chrome、Firefox、Edge、Safari（最新版推奨）
- **ペン専用モード**: タブレット・デジタルペン使用時に最適。ブラウザとデバイスがPointer Events APIに対応している必要があります
